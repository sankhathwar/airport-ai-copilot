# Airport Operations AI Copilot

An end-to-end Generative AI copilot for investigating airport operational issues using:

- Retrieval-Augmented Generation (RAG)
- Embeddings
- Vector Search
- Tool Calling
- Multi-Agent Workflows
- Guardrails
- Human-in-the-Loop Approval

## Airports

- SFO
- LAX
- JFK

## Project Flow

User Query
→ Understand
→ Retrieve
→ Investigate
→ Reason
→ Recommend
→ Validate
→ Approve
→ Execute
